# Installation

## Requirements

- Fedora Linux 44 Workstation (or newer)
- A working internet connection (some packages come from a COPR repository)

## 1. Clone the repository

```bash
git clone git@github.com:yehia-mg/musahi1.git
cd musahi1
```

## 2. Install packages

```bash
./install.sh
```

This installs everything from official Fedora repositories, plus `hyprpaper`
and `hyprlang` from the `solopasha/hyprland` COPR (enabled automatically by
the script).

## 3. Deploy the configs

```bash
./apply.sh
```

This copies every config in `config/` to `~/.config/`, backs up anything that
was there before (`~/.config/hypr.backup.<timestamp>`, etc.), and guards
against Hyprland's autogenerated `hyprland.lua` silently overriding our
`hyprland.conf` (see note below).

## 4. Apply a theme (colors + wallpaper)

```bash
./scripts/theme-switch.sh vagabond
```

Available themes: `vagabond` (default), `lain`, `evangelion`, `nature`.

Wallpapers are **not** included in this repository (see
[Wallpapers](#wallpapers) below) — add your own before switching themes, or
the script will apply colors only and leave the screen black.

## 5. Log out and select the Hyprland session

At the GDM login screen, click the gear icon next to the password field and
choose **Hyprland**, then log in normally.

> **Important:** on first login, Hyprland may autogenerate
> `~/.config/hypr/hyprland.lua`. If present, this file silently overrides
> `hyprland.conf` and none of this repo's configs will take effect. `apply.sh`
> already removes it automatically, but if you ever see the yellow
> "autogenerated config" warning banner on screen, run:
> ```bash
> rm ~/.config/hypr/hyprland.lua
> ```
> and fully restart the Hyprland session (`SUPER + M` to exit, then log back
> in) — a plain `hyprctl reload` is not enough for this specific check.

## Wallpapers

This repo intentionally ships with **empty** wallpaper folders
(`themes/<name>/wallpapers/`) — wallpapers are personal and not distributed
with the dotfiles. Add your own image(s) to the relevant folder, then run
`./scripts/theme-switch.sh <name>` to activate it. For best results, use an
image at least 1920x1080 — smaller images will look pixelated when scaled up.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `SUPER+Enter` / `SUPER+D` do nothing, no waybar | `hyprland.lua` overriding `hyprland.conf` | See warning above |
| `hyprpaper: command not found` | COPR not enabled | `sudo dnf copr enable solopasha/hyprland -y && sudo dnf install hyprpaper hyprlang` |
| `hyprpaper: error while loading shared libraries: libhyprlang.so.2` | `hyprlang` missing | `sudo dnf install hyprlang` |
| Waybar battery module errors out | Battery not on `BAT0`, or invalid format string | Check `ls /sys/class/power_supply/`, adjust `"bat"` in `config/waybar/config.jsonc` |
| swaync crashes right after Hyprland starts | Duplicate instance (systemd D-Bus activation + our own `exec-once`) | Already fixed — `swaync` starts via D-Bus activation only, not `exec-once` |
